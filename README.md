# AI News Summarizer Automation

## Project Overview

AI News Summarizer is an automated workflow built using n8n that collects news articles from RSS feeds, summarizes them using an AI model, and delivers the summarized news directly to an email inbox.

The main objective of this project is to reduce the time spent reading multiple news articles by providing concise AI-generated summaries.

## How It Works

1. **RSS Feed:** Fetches the latest news articles from RSS feeds.
2. **AI Summarization:** Processes the news articles and generates concise summaries using an AI model.
3. **Email Delivery:** Sends the summarized news to the configured email address.

## Technologies Used

- n8n – Workflow automation
- RSS Feed – News collection
- Generative AI / LLM – News summarization
- Email – Automated delivery

## Key Features

- Automatically collects news from RSS feeds.
- Generates concise summaries using AI.
- Delivers summarized news through email.
- Reduces manual effort in reading multiple news articles.
- Automates the complete news summarization process.

## Workflow

RSS Feed → AI Summarization → Email Delivery

## Project File

- `ai-news-summarizer-workflow.json` – Exported n8n workflow.

## How to Use

1. Download the workflow JSON file from this repository.
2. Import the JSON file into your n8n instance.
3. Configure the required RSS feed, AI model, and email credentials.
4. Execute the workflow.
5. Receive summarized news through email.
